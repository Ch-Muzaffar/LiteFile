Questions

Frequently asked questions

What is a HEIC file?

HEIC (High Efficiency Image Container) is Apple's image format, used by iPhone and iPad since iOS 11. It stores photos at roughly half the file size of JPG at the same visual quality.

The downside is that HEIC is not widely supported outside Apple devices — Windows 10/11 requires a paid codec from the Microsoft Store, and Android doesn't support it natively. Converting to JPG makes your photos universally compatible.

Does converting HEIC to JPG reduce quality?

Minimally. HEIC is technically more efficient than JPG, so the conversion involves a small quality trade-off. At 90% quality (the default setting), the difference is invisible to the eye in virtually all situations.

If you need maximum quality with no compression trade-off at all, choose PNG output — though the resulting files will be significantly larger than the original HEICs.

Can I convert multiple HEIC files at once?

Yes. Drop a folder or select multiple HEIC files and LiteFile converts them all in one batch. Each file is processed individually and you can download them all as a single ZIP archive or save each one separately.

What happens with Live Photos?

LiteFile extracts the still frame from Live Photos. The motion and audio component of a Live Photo cannot be converted to a static image format like JPG — only the photograph portion is saved. The tool will show a notice when a Live Photo is detected.

Should I choose JPG or PNG output?

JPG is the right choice for most photos. It produces smaller files and is universally compatible with all devices, browsers, and apps. Choose PNG only if you need truly lossless quality or if you are processing images that will be edited further.

For web use, social media, and general sharing, JPG at 85–95% quality is ideal. After converting, use Compress Image if you want to reduce file size further.
