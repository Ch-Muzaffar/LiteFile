Privacy Policy

Last updated: September 27, 2026

Short version: LiteFile processes your files entirely in your browser. We do not upload, store, or access your files. We collect no personal data and set no tracking cookies.

LiteFile is built on a simple premise: your files are yours. This policy explains the very few things we do — and the many things we don't — with information related to your use of litefile.cloud.

Files you process

Every tool on LiteFile processes files entirely within your browser. No file — image, PDF, or otherwise — is ever uploaded to a server. File data is handled by browser APIs (Canvas API, pdf-lib, WebAssembly) running locally on your device.

We have no technical capability to access, view, store, or transmit your files. This is not a policy choice — it is an architectural one. There is no server-side processing infrastructure.

Personal information

We do not collect personal information. We do not ask for your name, email address, payment information, or any other identifying information. There is no account system on LiteFile.

Cookies and local storage

LiteFile stores one value in your browser's local storage: your preferred color theme (dark or light). This value never leaves your device. No cookies are set. No cross-site tracking is performed.

Analytics and usage data

LiteFile currently runs no analytics. We do not track page views, tool usage, session duration, click patterns, or any other behavioral data.

If we add analytics in the future, we will use a privacy-preserving, cookieless solution (such as Plausible Analytics or Fathom) that does not share data with advertising networks, does not use fingerprinting, and does not track individuals across websites. This policy will be updated if that changes.

Third-party libraries

Some tools lazy-load open-source libraries from content delivery networks (CDNs) at the time you first use a feature:

  • pdf-lib — PDF processing (loaded from jsDelivr CDN)
  • JSZip — ZIP archive creation (loaded from jsDelivr CDN)
  • ONNX Runtime Web — AI model inference for background removal
  • RMBG-1.4 model weights — background removal AI model
  • heic2any — HEIC to JPG conversion (loaded from jsDelivr CDN)

These CDN requests may log your IP address and the request timestamp, per standard CDN access logging. No file data is included in these requests — only the library file itself is fetched. We do not control CDN server logs and are not responsible for them.

Hosting infrastructure

LiteFile is hosted on a static file hosting provider. The hosting provider may retain standard web server access logs including IP addresses and requested URLs. This is standard practice for all websites and outside our control. No file data is ever included in these logs because no file data is ever transmitted.

Children

LiteFile does not knowingly collect information from children under 13. Because we collect no personal information at all, the site is appropriate for use by any age.

Your rights

Because we collect no personal data, there is nothing for us to access, export, or delete on your behalf. If you have concerns about data retained by CDN providers referenced above, please contact those providers directly.

Changes to this policy

If we make material changes to this policy, we will update the "last updated" date at the top of this page. Because we hold no personal data, we have no way to notify users directly of changes. We encourage you to review this page periodically.
