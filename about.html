LiteFile is a collection of free, fast, browser-based tools for images and PDFs. Everything runs locally in your browser — your files never leave your device, and we never ask for your email.

Why LiteFile

Most file tools are asking too much

Upload your document to our servers. Create an account. Wait for processing. Hope your file doesn't end up indexed, logged, or used for training. That's the standard experience. We built LiteFile because we were tired of it.

Every LiteFile tool uses browser-native APIs — the Canvas API for images, pdf-lib for PDFs, and ONNX Runtime Web for AI inference. Processing happens entirely within your browser tab. No network request is ever made with your file data.

The result is something that's simultaneously more private, faster, and simpler to use than the alternatives. There's no server lag because there's no server.

What "client-side" actually means

Your files never leave this tab

Files are processed using the Canvas API, pdf-lib, and WebAssembly inside your browser tab. No file data is ever sent over a network connection to any server.

Free forever

Questions

Frequently asked

Are my files really never uploaded?

Yes. Every tool processes files using browser APIs — the Canvas API for image operations, pdf-lib for PDF operations, and ONNX Runtime Web for background removal. You can verify this yourself: open your browser's Network tab (F12), then use a tool. No requests containing your file data will appear.

What file formats are supported?

Image tools support JPG, PNG, and WebP. The HEIC to JPG converter accepts HEIC and HEIF files (common on iPhones and iPads). Background removal works on JPG, PNG, and WebP. PDF tools accept standard PDF files.

Is there a file size limit?

There is no server-side limit — since there's no server. Your browser's available memory sets a practical ceiling. Most modern devices handle files up to 50–100 MB without issue. Very large PDFs (200+ pages) or extremely high-resolution images may process more slowly on older hardware.

Does LiteFile work offline?

Most tools work offline once the page has loaded and cached. The background remover requires an initial download of the AI model (~170 MB on first use), after which it runs completely offline. Tools that use pdf-lib or JSZip need a connection the first time they run on a given device.

Will LiteFile always be free?

Yes. All tools are free and will remain so. We may add unobtrusive display ads in the future to cover hosting costs — but there will never be a paywall, watermarks, or a required sign-up for full functionality.
