Questions

Frequently asked questions

Which image formats can I convert?

Input: JPG, PNG, WebP, GIF, BMP, HEIC, HEIF. Output: JPG, PNG, WebP, BMP. You can mix input formats in a single batch — convert a folder containing both JPGs and PNGs to WebP in one go.

What is WebP and why should I use it?

WebP is a modern image format from Google that produces files 25–35% smaller than equivalent JPG or PNG images at the same visual quality. It supports transparency (like PNG) and both lossy and lossless compression.

All modern browsers support WebP, making it the best choice for images on websites. If you're optimising images for the web, convert to WebP.

Does converting between formats reduce quality?

It depends on the output format. Converting to JPG or WebP uses lossy compression — there is a small quality trade-off, controlled by the quality slider. At 90% quality, the difference is invisible to the eye.

Converting to PNG or BMP is lossless — no quality is lost. Note that converting from a lossy source (e.g. JPG) to a lossless format (PNG) will not recover quality that was already lost in the original.

Can I convert multiple images at once?

Yes. Drop a folder or select multiple files and LiteFile converts them all in one batch to your chosen output format. Download individual files or get them all as a single ZIP archive.

Does this work with iPhone HEIC photos?

Yes. HEIC and HEIF files (the format used by iPhone and iPad cameras) are supported as input. They are converted using the open-source heic2any library, which is loaded on demand when a HEIC file is detected. All HEIC processing happens locally in your browser.
